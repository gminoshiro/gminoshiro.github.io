Photo Privacy プライバシーポリシー

最終更新: 2025年12月25日

Photo Privacy（以下「当アプリ」）は、ユーザーのプライバシー保護を最優先に設計されたiOSアプリケーションです。
本プライバシーポリシーでは、当アプリがどのようにユーザーの情報を扱うかを説明します。

1. 収集する情報

当アプリは、ユーザーの個人情報を一切収集しません。

データ種別 収集 説明
写真・動画❌ 収集しない写真へのアクセスはメタデータ表示・編集・削除のみに使用し、外部送信されません
位置情報❌ 収集しない写真のEXIF内の位置情報を表示・編集する機能のみで、デバイスの位置情報は使用しません
連絡先❌ 収集しない当アプリは連絡先にアクセスしません
識別子❌ 収集しない広告IDやデバイスID等を収集しません
使用状況データ❌ 収集しないアクセス解析ツールを使用していません
課金情報❌ 収集しないサブスクリプションはAppleが管理し、当アプリは決済情報にアクセスしません

2. データの使用目的

当アプリは、ユーザーのデータを外部サーバーに送信しません。

すべての処理は、以下の目的でのみデバイス内で行われます：

  • 写真・動画のメタデータ（EXIF情報）の表示
  • メタデータの編集（撮影日時、位置情報、カメラ情報など）
  • メタデータの削除（全削除または位置情報のみ削除）
  • 編集後の写真のフォトライブラリへの保存
  • アプリ設定の保持

3. データの保存場所

すべてのデータは、ユーザーのiPhone/iPad内にのみ保存されます。

データ種別 保存場所 暗号化 iCloudバックアップ
写真・動画フォトライブラリ✅ iOS標準✅ フォトライブラリ設定に従う
アプリ設定UserDefaults✅ iOS標準✅ 含む
サブスク情報StoreKit✅ Apple管理✅ Apple管理

4. 第三者への提供

当アプリは、ユーザーのデータを第三者に提供しません。

以下のサービスも使用していません：

  • ❌ Google Analytics
  • ❌ Firebase Crashlytics
  • ❌ Facebook SDK
  • ❌ 広告SDK
  • ❌ その他のトラッキングツール

5. 必要な権限

当アプリは、以下の権限のみを使用します：

  • 写真ライブラリアクセス（読み込み）: メタデータを表示するため
  • 写真ライブラリアクセス（保存）: メタデータ削除後の写真を保存するため

これらの権限は、PhotoKitフレームワークを通じてiOSの標準的なプライバシー保護機能の下で使用されます。

6. セキュリティ

6.1 ローカル処理

  • 完全なローカル処理: すべてのメタデータ処理はデバイス内で完結
  • 外部送信なし: 写真データを外部サーバーに送信しません
  • 元データ保護: 削除処理は新しい写真として保存し、元画像は変更しません

6.2 StoreKit

  • Apple管理: サブスクリプションはAppleのStoreKitで管理
  • 決済情報保護: 当アプリはクレジットカード情報にアクセスしません

7. サブスクリプション

当アプリは、以下のサブスクリプションプランを提供しています：

  • 月額プラン: ¥200/月（7日間無料トライアル）
  • 年額プラン: ¥1,500/年（7日間無料トライアル）
  • 買い切りプラン: ¥5,000（トライアルなし、永久利用）

すべてのプランで全機能が無制限に利用可能です。サブスクリプションの管理はiOSの設定アプリから行えます。

8. プライバシーポリシーの変更

当アプリのプライバシーポリシーを変更する場合は、本ページを更新し、アプリ内でお知らせします。

Photo Privacy Privacy Policy

Last Updated: December 25, 2025

Photo Privacy (the "App") is an iOS application designed with user privacy as the top priority.
This Privacy Policy explains how the App handles user information.

1. Information We Collect

The App does NOT collect any personal information.

Data Type Collected Description
Photos & Videos❌ NoPhoto access is used only for metadata display, editing, and removal; never transmitted externally
Location❌ NoOnly displays/edits location from photo EXIF; does not use device location services
Contacts❌ NoThe App does not access contacts
Identifiers❌ NoNo advertising IDs or device IDs collected
Usage Data❌ NoNo analytics tools used
Payment Info❌ NoSubscriptions managed by Apple; the App has no access to payment information

2. How We Use Data

The App does NOT transmit user data to external servers.

All processing is performed locally on the device for the following purposes:

  • Displaying photo and video metadata (EXIF information)
  • Editing metadata (date/time, location, camera info, etc.)
  • Removing metadata (all metadata or location only)
  • Saving edited photos to the photo library
  • Storing app settings

3. Data Storage

All data is stored only on the user's iPhone/iPad.

Data Type Storage Encryption iCloud Backup
Photos & VideosPhoto Library✅ iOS Standard✅ Follows Photo Library settings
App SettingsUserDefaults✅ iOS Standard✅ Included
Subscription InfoStoreKit✅ Apple Managed✅ Apple Managed

4. Third-Party Sharing

The App does NOT share user data with third parties.

We do not use the following services:

  • ❌ Google Analytics
  • ❌ Firebase Crashlytics
  • ❌ Facebook SDK
  • ❌ Advertising SDKs
  • ❌ Any tracking tools

5. Required Permissions

The App uses only the following permissions:

  • Photo Library Access (Read): To display metadata
  • Photo Library Access (Write): To save photos after metadata removal

These permissions are used through the PhotoKit framework under iOS's standard privacy protections.

6. Security

6.1 Local Processing

  • Complete Local Processing: All metadata processing is done on-device
  • No External Transmission: Photo data is never sent to external servers
  • Original Data Protection: Removal creates a new photo; original is unchanged

6.2 StoreKit

  • Apple Managed: Subscriptions managed by Apple's StoreKit
  • Payment Info Protection: The App has no access to credit card information

7. Subscriptions

The App offers the following subscription plans:

  • Monthly Plan: ¥200/month (7-day free trial)
  • Yearly Plan: ¥1,500/year (7-day free trial)
  • Lifetime Plan: ¥5,000 (no trial, permanent access)

All plans include unlimited access to all features. Subscriptions can be managed in iOS Settings.

If we update this Privacy Policy, we will update this page and notify users within the App.
